# Changelog

Every release of AI World, newest first, in the words it went out with.

A release here is one feature rather than one night — that is a rule this project keeps
deliberately, so the list is long and each entry is small. What a version *says* is what somebody
thought it was for on the morning it shipped, which is more useful a year later than a tidy summary
written afterwards.

The ten most recent are also in the [README](README.md#changelog). Older ones live only here.

Versions are `major.minor.patch` on the chart, the image, the package and the tag all at once:
`tools/release.ts` moves them together, because a chart pinning a version whose image was never
built is a cluster that cannot start.

## v0.1.0 — 2026-09-06

The first tagged version of ai.world, cut so that a Kubernetes deployment has something to name.

The Helm chart's `appVersion` is `0.1.0` and its image tag defaults to that, but pushes to main only publish `latest` and the commit sha — semver tags come from a release. Without this tag the chart pinned an image that did not exist, and the first reconcile of a cluster would have ended in ImagePullBackOff.

Publishing this produces `ghcr.io/christhomas/ai-world:0.1.0` and `:0.1`, built natively for amd64 and arm64 and joined into one manifest list, so a Raspberry Pi and a VPS pull the same name and each get the right thing.

What it contains: the game as it stands — a polygon world grown from a seed, villages, quests, a market and an economy, and a world server holding the little that players share, with the built page served from the same origin so nothing has to be configured with a server address.
